# 选人自动配置界面样例

这些截图来自本地生产构建的隔离渲染页面。英雄与图标使用 Data Dragon 资源，方案、胜率、样本量和客户端状态使用模拟数据；未连接真实账号，也未执行真实 LCU 写入。

- `selection-ranked.png`：430×900，经典模式、推荐出装与应用结果。
- `selection-aram.png`：430×900，切换到普通大乱斗并点击另一套方案后的反馈。
- `selection-minimum.png`：390×520，紧凑英雄区、装备与固定状态栏。
- `selection-mayhem-minimum.png`：390×520，海克斯装备参考。

交互检查覆盖选人状态变化后自动切页、残留弹窗关闭、普通轮询不打断浏览、设置开关移除、方案切换、缺少分路阻止写入与配置失败重试。Windows 实际对局写入仍需实机验收。
