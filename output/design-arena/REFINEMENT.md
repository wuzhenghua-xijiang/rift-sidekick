# 街头暴走 V2

按用户确认的两个条件精修：保留街头暴走的视觉性格；登录后继续使用原来的客户端吸附小窗。

- 登录前：1100×740 独立启动窗，燃橙拼贴与官方「双城之战2 破碎者 金克丝」原画；右侧为墨黑登录台、橙色大标题、纸白输入框与醒目的启动按钮。启动优化与官方登录分别可见，验证码和大区保留在官方窗口。
- 登录后：430px 宽吸附助手，390px 最小档；47px 功能栏、单列配装、独立内容滚动、54px 固定底部操作。布局并非缩小首轮桌面工作台。
- 针对「小窗偏素」的反馈：放大街头暴走本身的视觉语言。英雄区采用燃橙斜切；选中方案以墨黑底、橙色大胜率和硬边投影突出；替代方案保留纸白清单；导航选中态与固定底栏使用整块燃橙。大厅原画与赛后战报同步加强对比，没有增加解释文案。
- 阶段：大厅等待选人、选人配装、赛后复盘与荣誉示意；所有状态均可在预览工具栏切换。
- 次级功能：对位、教练、战绩、云顶、图鉴、语音都在小窗内，OpenAI 统一于设置页的一套接口、Key 与模型，提示词分别设置。
- 查看方式：「贴边场景」展示客户端与助手的相邻关系；「小窗 1:1」查看真实排版宽度；最小档为 390×560。

实际宽度取自 `src/main/index.ts`；贴边与高度跟随取自 `src/main/dock-bounds.ts`、`src/main/windows-dock.ts`。当前为浏览器原型，未修改这些生产文件。实际 Windows 吸附、显示隐藏和文本可读性留待生产接入后验收。

首轮其他方案、截图和审阅记录保留。当前截图位于 `../playwright/overdrive-v2/`。浏览器验收见 `validation-overdrive-v2.json`；账号、连接、推荐与操作反馈均为示意，不提交或保存输入，语音保持静音。
