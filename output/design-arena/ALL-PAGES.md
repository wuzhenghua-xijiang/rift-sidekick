# 街头暴走 · 全页设计

用户要求全部页面延续备战页的视觉力度。本轮只更新本地原型，保留已选的燃橙、墨黑、纸白、硬边与英雄图像，不修改 React / Electron 生产实现。

| 功能 | 构图 | 示意交互 |
| --- | --- | --- |
| 对位 | 双方英雄对战海报、VS、第四枪提示 | 对线 / 连招切换、刷新 |
| 教练 | BP 海报、带英雄头像的推荐次序 | 选择 / Ban / 阵容切换、选择推荐、生成反馈 |
| 战绩 | 4W / 1L 战报、英雄原画、KDA | 展开单场复盘、刷新 |
| 云顶 | 墨黑六角棋盘、核心英雄与装备 | 点击棋子 / 核心英雄、复制示意反馈 |
| 图鉴 | 黑橙英雄卡册、搜索与位置筛选 | 中英文 / 外号 / 拼音检索、组合筛选、空状态与清除、选择英雄 |
| 语音 | 静音播报台、事件台词 | 开关、模式、音量、事件选择与静音波形反馈 |
| 设置 | 黑橙共享连接面板、独立提示词 | OpenAI / 语音 / 游戏切换、提示词切换、偏好开关、保存 / 测试示意 |

底部操作按当前任务变化；保存、生成、复制等动作始终可见，主体内容独立滚动。OpenAI 依然只有一处接口地址、API Key 与模型，教练与语音共用连接。

默认宽 430px，最小档 390px；预览高度分别 720px / 560px。页码可用 `section=matchup|coach|history|tft|champions|voice|settings` 直达，设置可加 `tab=openai|voice|game`。`overdrive-pages.html` 为可点击的八页设计板，附 `size=minimum` 查看最小档。

所有推荐、账号、战绩、英雄分路、阵容、装备、连接与操作反馈均为布局示意。声音保持静音，不调用游戏、OpenAI、音频或本地存储；表单输入不会保存或发送。赛后数据与站位均不能当作真实建议。

截图位于 `../playwright/overdrive-all-pages/`。验证记录见 `validation-overdrive-all-pages.json`。实际 Windows 吸附与完整无障碍验收未由本地原型代替。
