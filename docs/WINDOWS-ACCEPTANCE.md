# Windows 实机验收清单

当前状态：**开发方尚未执行 Windows 实局验收**。2026-10-27 用户已反馈符文与召唤师技能生效，但装备在商店未显示、吸附有间隙。0.1.8 针对上述问题进行修正；0.2.0 重做界面并加入登录、启动、教练和战斗语音，计时改用原生小地图；0.2.1 改为先优化再直接启动国服官方客户端，并移除 QQ 输入与自动填写。用户确认双击 `Launcher\Client.exe` 可打开官方登录窗口，但助手 0.2.1 点击启动未打开客户端。Windows 测试已复现残留后台进程导致跳过启动的问题，0.2.2 修复此判断；仍需 Windows 10/11 x64 实机复测。

建议先在自定义对局中进行配置验收。记录 Windows 版本、LOL 区服/版本、屏幕缩放比例及助手安装包 SHA-256。

## 0.2.0：原生小地图计时

下列条目用于 0.2.0 安装包的 Windows 验收。

- [ ] 连接客户端后，在偏好设置看到“自动开启小地图营地计时”与真实的检查/成功/失败状态。
- [ ] 原选项关闭时，助手只将 `HUD.MinimapEnableAllTimers` 开启，保存并读回；其他 HUD、声音、按键设置保持原值。
- [ ] 开局后，在小地图各营地对应位置自动显示游戏原生计时；无需手动记录击杀，显示遵循游戏当前视野与模式规则。
- [ ] 调整游戏内小地图大小、左右位置和屏幕 DPI 后，计时由游戏正确跟随；不叠加助手手动列表。
- [ ] 从 0.1.8 升级并保留旧偏好后，也不出现手动列表、悬浮窗、快捷键或托盘计时入口；不再为计时轮询 2999 游戏数据。
- [ ] 已开启时只读取确认；接口未提供选项时不盲写，提示 Esc → 界面 → 小地图野怪计时 → 高级。
- [ ] 加载、对局和重连期间不发起 PATCH/保存；回大厅后重新检查；账号切换时不沿用旧检查结果。
- [ ] 关闭自动配置后不再自动写入；游戏内原来已开启的选项不会被反向关闭。
- [ ] 断连、保存失败或读回不一致不显示成功；重试可恢复，错误不影响符文/装备配置。

## 0.2.0：局内战斗语音

- [ ] 默认开启；升级后显式关闭的偏好保持关闭，支持夸夸/调侃分开关闭、音量与间隔、试听和事件专属台词。
- [ ] 确认 Windows 中文语音可用；缺失时提示安装，不声称已播放。测试默认静音，需要听音验收时音量最多 2%。
- [ ] 经典、普通大乱斗与海克斯对局采集真实事件；大厅、赛后、云顶、斗魂、身份不匹配或观战不触发。
- [ ] 残血击杀、多杀、团灭和共同击杀/助攻对应正确台词；连续阵亡才轻度调侃，不以辅助人头少评价表现。
- [ ] 连杀合并、冷却与事件去重生效；死亡撤销未播报的存活夸奖，重连不补播历史事件。
- [ ] 助手隐藏到后台后仍播报；关闭、静音、离开对局或退出会停止采集、AI 请求与声音，不残留待播。
- [ ] 配置 OpenAI/兼容服务的 Base URL、模型和 Key，验证匿名事件识别与专属台词；四秒超时、限流、鉴权失败回退基础识别，迟到响应不播报。
- [ ] Key 仅以系统加密密文保存、不回传前端；更换服务地址需重新填写 Key；LOL 提示词和各事件台词重启后保留。

## 安装和窗口

- [ ] 运行 x64 安装器，可选择目录，桌面/开始菜单快捷方式有效，正常打开/关闭/卸载。
- [ ] 启动第二个实例只显示已有窗口。
- [ ] 通知区域出现助手图标，双击和右键“显示助手”可唤回；右键“退出助手”终止程序和辅助进程。安装资源目录包含 `tray.ico`。
- [ ] 托盘可用时右上角提示“隐藏到托盘”，关闭后保持后台且吸附轮询不立即弹回；托盘初始化失败时能正常关闭，不遗留无法唤回的进程。
- [ ] 在窗口隐藏状态注销/关机不会被关闭拦截阻止；下次启动正常连接。托盘入口在游戏中主动唤回时不引起重复隐藏/显示。
- [ ] 先启动助手再启动 LOL、先启动 LOL 再启动助手，两种顺序均可连接。
- [ ] 客户端移动/缩放时助手跟随右侧；右侧空间不足时转左侧，工作区边界保持可见。
- [ ] Windows 10/11 的 100%/125%/150% 缩放下，右侧和左侧均贴合客户端可见边框，无 6px 人工间隙；多屏切换后仍贴合。
- [ ] 客户端最小化后助手隐藏；恢复后显示且不抢焦点。切换到其他软件时助手不盖住其他软件。
- [ ] 100%/125%/150% 缩放和双屏负坐标下位置正确；关闭吸附后可独立移动窗口。
- [ ] 无客户端时仍可打开、移动助手并浏览攻略。
- [ ] 从选人进入 GameStart/InProgress 后助手自动隐藏；Reconnect 持续隐藏，客户端接口短暂断连不会让助手突然显示。
- [ ] 对局结束进入 PreEndOfGame/WaitingForStats/EndOfGame，或游戏取消后返回大厅时，窗口恢复一次且不抢焦点；结算阶段自动切到本局复盘，之后手动切页不会每次轮询都跳回。
- [ ] 开启/关闭吸附两种情况均能开局隐藏和赛后恢复；客户端最小化、重新启动助手、游戏中主动唤回时无反复闪烁或覆盖游戏。

## 识别与自动配置

- [ ] 排位单双排、灵活排位、匹配、自定义峡谷显示“经典模式”；普通大乱斗与海克斯大乱斗分别识别，不能仅凭同一地图混淆模式。
- [ ] 队列 2400 或 KIWI 识别为海克斯大乱斗，优先于普通 ARAM；无客户端时可手动切换三个模式查看方案。
- [ ] 云顶识别后进入云顶页面；斗魂及未知模式不会写入峡谷符文/装备。
- [ ] 预选英雄时界面跟随但不写入；锁定后优先应用已保存偏好，无偏好时用胜率最高的方案，海克斯用首套装备参考。
- [ ] 进入选人、换英雄/重随/交换、锁定及模式变化时自动回到英雄选择页，关闭残留搜索弹窗；普通轮询与敌方选人不会打断手动浏览。
- [ ] 离线、未锁定、方案加载、缺少方案、缺少分路、需要恢复、游戏阶段的底部提示准确；仅允许本局匹配的英雄、模式和分路写入。
- [ ] 选人时浏览其他英雄或模式出现“回到本局”，旧/异英雄方案不能写入；回到本局恢复正确英雄、模式和客户端分路。
- [ ] 有分路时正确读取；无分路的峡谷对局先提示点选分路；大乱斗不要求虚构分路。
- [ ] 最快锁定、最后几秒锁定、换英雄/换分路、取消队列、普通/海克斯大乱斗重随或交易，均不会应用旧英雄方案。
- [ ] 无需进入设置，锁定后直接应用符文、召唤师技能与装备；设置中不再出现自动配置和技能同步开关。保留旧版 `autoConfig: false`、`includeSpells: false` 偏好升级后仍自动生效。
- [ ] 锁定后点击其他方案会立即应用并保存偏好，普通轮询不重复写入；撤回后同一选人状态不会被自动配置重新覆盖。
- [ ] 选择不同方案后重开同英雄/分路/模式对局能记住偏好。
- [ ] 进入加载或游戏后只查看方案，按钮不可写入；启动于游戏中时能读取公开会话返回的当前英雄。

## 写入与恢复

- [ ] 预先记录原符文页、装备方案和技能。配置后优先新增/复用助手自己的符文页；符文页已满时自动使用可编辑页面，并可通过恢复快照还原。
- [ ] 装备进入商店方案，仅有核心成装、鞋子、后续成装，不包含出门装、药水和合成小件。
- [ ] 卡片主系显示实际基石图标及名称，副系显示所选两枚小符文图标，悬停可看名称；图标来自 LOL 当前资源目录。应用后完整九个符文选择合法且当前页切换正确。
- [ ] 卡片展示两枚推荐召唤师技能的官方图标，悬停名称与写入 ID 对应；最窄窗口布局正常，海克斯装备参考不显示不适用的技能推荐。
- [ ] 经典与普通大乱斗始终同步两枚推荐技能，写入后读回一致；读取不到原技能时不做部分配置，显示重试入口。
- [ ] 符文页满时自动选择可编辑页面应用推荐；没有可编辑页面时明确提示。
- [ ] 海克斯大乱斗只写装备：即使符文页已满或符文接口不可用仍可配置，不更改该模式技能。撤回只恢复此次涉及的内容。
- [ ] 点击撤回后原符文、装备和同一局技能恢复；换到另一局不会恢复旧局技能。
- [ ] 写入时关闭客户端或断开接口，重新打开后提示恢复；成功恢复后才能继续配置。
- [ ] 未完成恢复期间换账号，拒绝在新账号写入旧账号快照。
- [ ] 配置后手动修改助手页/装备，再点撤回会提示冲突并保留手动修改；“保留当前配置”可解除恢复状态。
- [ ] 客户端与资源或已知统计主次版本不一致、失效装备/符文、超时等情况均停止写入并给出原因。

## 数据与辅助

- [ ] 每个方案独立一张紧凑卡片，最多 5 套；不同卡片在核心成装或主副系上有实际差异，点击选用与偏好保存正常。
- [ ] 方案按胜率从高到低排列，缺失胜率排最后，同胜率保持顺序；选择靠后方案后刷新或重启，仍选中保存的方案且不会将其置顶。
- [ ] 卡片突出推荐装备，其后展示符文和技能；“已应用”仅对应本局、英雄、分路、模式与读回成功的方案，换局不残留成功标签。说明折叠，对位摘要和热门榜位于出装之后，失败与恢复提示保持可见。
- [ ] 430×900 和最小 390×520 下功能导航、滚动内容、固定配置栏均可操作；长名称不挤出官方符文/技能图标。
- [ ] 经典和普通大乱斗独立查询，来源、样本量和统计版本可见；六个装备图标无重复、都是成装，切换英雄时不残留上一英雄方案。
- [ ] 海克斯卡片明确标为普通大乱斗装备参考，不展示常规符文或海克斯胜率，不套用普通大乱斗对位数据。
- [ ] 数据源限流或断网时显示重试提示，无反复请求循环；恢复网络后可重新获取。
- [ ] 对位页只筛选已亮出的敌方英雄；胜率含义明确为英雄对阵整场数据。
- [ ] 经典模式有明确敌方分路时，同位置英雄锁定后自动显示对位小抄；预选、未完成的选人动作不会提前指定对手。
- [ ] 敌方没有分路时，仅唯一高度常用该分路的已锁定英雄可被标记为“推测”；多个摇摆候选不强行指定，不根据队伍排列判断位置。
- [ ] 更正对手只列已锁定敌人，支持中文名/外号；换自己英雄、换分路或换选人会话清除旧手选。离线可搜索全部英雄研究对位。
- [ ] 对位小抄中的对手注意事项、己方技巧和分路提醒显示正常；缺少技巧或对阵数据时局部提示，不阻塞方案。
- [ ] 当前分路热门榜按登场率排序，胜率、样本量、统计版本和全球全段位排位范围明确；切换分路/点英雄时无旧数据残留，大乱斗/海克斯不显示峡谷榜。
- [ ] 自己的战绩与客户端一致，KDA 不误取队友；翻页最多 200 场，段位和熟练度独立失败不影响其他数据。
- [ ] 战绩回放下载和观看请求符合客户端实际支持范围；过期/不支持的回放给出失败提示。
- [ ] 云顶阵容及代码对应当前赛季，粘贴到队伍规划器后能正确解析。
- [ ] 连续使用一局观察 CPU、内存及 FPS/延迟；记录前后数值，目前没有可声称通过的性能结论。

## 本局分析与荣誉点赞

- [ ] 结算到达前显示等待并有限次重试；读取本局数据不会发起荣誉写入。
- [ ] KDA、胜负及英雄属于当前账号和当前对局；客户端尚未返回明确胜负或换局时不显示旧局分析。
- [ ] 同次运行中切换到其他页面再返回，战报不消失；回大厅/继续匹配保留“最近一局战报”，只读且不再出现投票入口。
- [ ] 断开客户端或进入下一局选人清除旧战报，新选人自动返回推荐页；下一局结算再次自动打开复盘，不受上局切页影响。
- [ ] 参团率、伤害占比、补刀/分钟、视野及我方伤害对比与客户端一致。缺失字段显示“—”，缺少完整队伍数据时不虚构占比。
- [ ] 票数和可选玩家与客户端票单一致，剔除自己/机器人，区分队友和对手；预选不等于提交，必须点击“一键点赞”才写入。
- [ ] 达到票数上限后禁用额外选择；取消一个选择后可选其他玩家，按钮中的人数随选择更新。
- [ ] 点击时重新核验当前账号、对局、阶段、资格和票数；票数已变或玩家已获赞时提示重选且不写入。
- [ ] 一次手动提交按勾选玩家逐人发出 HEART 后完成投票；成功后无法重复提交，同局刷新也不重复投票。
- [ ] 写入开始前失败可刷新后重试；部分投票成功后接口超时，明确提示结果待确认，不再自动或重复写入，也不尝试不同端点。
- [ ] 荣誉接口不可用时仍能查看本局分析；切换账号或离开结算后拒绝给旧局投票。

## 应用内更新

- [ ] 从已安装的 0.1.8、0.2.0 或 0.2.1 检查更新到 0.2.2，确认镜像检索、版本提示和进度；开发版不得执行安装。
- [ ] 断网或下载失败后可重试，不影响已有攻略及配置；校验失败不能安装，下载后篡改缓存也应拒绝。
- [ ] 选人、匹配、加载/对局及配置或点赞提交中拒绝安装；回到大厅后可继续，普通关闭不自动安装。
- [ ] 点击安装后静默覆盖并重新启动，显示新版本；偏好、快照、托盘和单实例正常。
- [ ] 系统权限/杀毒拦截或磁盘不足时，仍可重新启动原版并再次尝试。更新清单签名不等同于 Windows 代码签名。

## 装备显示

- [ ] 首次没有助手套装时，配置后客户端装备收藏中存在对应的「Rift · 英雄 · 方案」，其他自建套装保留；重复配置只复用助手 UID。
- [ ] 进入游戏按 P → 物品套装，选择该英雄套装，能看到核心、鞋子和后续成装；切换套装后与推荐卡片一致。原生“推荐”页不会被此操作替换。
- [ ] 新建接口失败/超时/未保留套装、地图/类型或符文写入读回不符时不报告成功；补偿不删除玩家其他套装。

## 直接启动与性能优化

- [ ] 未运行游戏时，启动助手即自动扫描注册表、快捷方式和常见目录；非常规安装路径由后台磁盘目录扫描找到。找到后无需手动选择，位置自动记住；游戏搬家后重查，中文、空格、非系统盘正常；不启动 WeGame。
- [ ] 0.2.1 默认查找 `Launcher\Client.exe`，不扫描或启动 `TCLS\Client.exe`、`WeGameLauncher\launcher.exe` 或 WeGame。旧缓存为 TCLS 时自动改用同一根目录的官方客户端；官方入口缺失时明确提示，不回退 TCLS。
- [ ] 官方客户端要求管理员权限时正常出现 Windows 授权；取消授权、权限拒绝、依赖缺失时显示具体原因与实际启动路径，并恢复本次优化。创建进程后仍需确认本安装目录的官方窗口；意外出现新的 WeGame 进程或未确认窗口时不报告启动成功。
- [ ] 账号登录、官方保存的登录状态、验证码/扫码和大区选择全部在官方窗口完成，LCU 实际连接后助手才进入吸附小窗。本次只验收国服。
- [ ] 启动前记录 `powercfg /getactivescheme`。点击启动后先显示资源检查、实际优化及核验，全部必要步骤完成后才出现客户端进程；重复点击只启动一次。
- [ ] 拒绝电源计划修改或模拟核验失败时显示原因，不启动客户端；恢复原设置后可重试。设备无高性能计划、CPU/内存紧张时明确提示，不报告虚构的性能提升。
