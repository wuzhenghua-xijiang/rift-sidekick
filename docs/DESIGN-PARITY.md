## 验收证据

- 八页分别验证 430×720 与 390×560；登录 1100×740 与 840×640；大厅；设置的语音 / 游戏子页。共 23 个场景，无横向溢出、可见坏图或浏览器脚本错误。所有小窗底栏高 54px，英雄区高 116px，与原稿的计算尺寸相同。
- 赛后胜利、失败、统计缺失、加载失败分别在两档小窗检查，另 8 个场景。展开复盘、提交一次荣誉投票、进入历史战绩均完成桥接验证。
- 操作验证：登录输入校验和密码显隐、两种启动入口、方案选择 / 应用 / 撤回、英雄与分路搜索、对位切换与刷新、建议生成与 Ban 选中、回放、阵容复制、静音、共用连接保存 / 测试 / 清除、独立提示词、失败重试及旧推荐清除。
- `npm run typecheck` 与 `npm run build` 通过；`npm test`：265 通过，2 跳过。
- 补充检查：从历史战绩返回本局战报、大乱斗对位页返回入口、十组设计对照图片加载均通过。
- 原始记录：`output/implementation-preview/parity-validation.json`、`parity-postgame-validation.json`、`parity-final-validation.json`；重复检查脚本也在该目录。

## 数据导致的合理差异

胜率、样本、英雄数量 / 顺序、方案装备数量、教练建议和行数取自当前数据，不能照抄原稿的示例。图鉴尚未选择分路时用英雄称号，避免伪造英雄分路。云顶单位无法匹配头像时保留真实名称；装备暂无图标时显示装备名称。实际模型、加载、错误和忙碌状态均保留。

浏览器桥接验证不替代 Windows 官方客户端启动、LCU、窗口吸附、跨屏 DPI 与实际播报。

## 2026-10-28：10 套推荐与去重

沿用当前方案卡片、字体、配色和固定底栏，以数据增加候选数量，不更改原有构图。[430×720 预览](../output/playwright/recommendations-fizz-430.png) / [390×560 预览](../output/playwright/recommendations-fizz-390.png) 使用 OP.GG 16.21 小鱼人普通大乱斗真实推荐快照，客户端连接与应用操作仍为明确标注的静音验收桥。

- 两档均显示 10 套；无横向溢出、可见坏图或浏览器脚本错误，底栏高 54px 且固定贴底。第 10 套可滚动到达，点击只发送一次应用请求，并显示「已应用」。
- 当前快照按既有胜率排序后，最前为不灭之握、心之钢、无终恨意、璀璨回响、水银之靴、狂徒铠甲和荆棘之甲；另保留铁板靴变体。肉装及法装都来自来源真实样本，原画仍使用实际英雄。
- 用真实统计分别检查小鱼人普通/海克斯参考、阿狸中路及墨菲特普通大乱斗，均得到 10 个不同的完整符文＋装备键。没有联合样本时不声称整套胜率，海克斯不提供常规符文或海克斯胜率。
- 完整符文、装备顺序和分组去重、坦克路线、有限网络重试及限流回退均有回归测试。本机 `npm test`：328 通过、6 项 Windows 专用测试跳过，共 334 项；类型检查和生产构建通过。
- 已完成桌面浏览器目视检查。脚本见 [推荐验证](../output/implementation-preview/recommendations-validation.js)，结果见 [记录](../output/implementation-preview/recommendations-validation.json)，原始统计及目录缩减快照在 `src/main/fixtures/fizz-aram-16.21.json`。

这些改动尚未包含在已发布的 0.2.3 中。真实 Windows 国服游戏商店第一套显示与自动配置仍待实机复测。
