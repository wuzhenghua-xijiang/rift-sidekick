## 验收证据

- 八页分别验证 430×720 与 390×560；登录 1100×740 与 840×640；大厅；设置的语音 / 游戏子页。共 23 个场景，无横向溢出、可见坏图或浏览器脚本错误。所有小窗底栏高 54px，英雄区高 116px，与原稿的计算尺寸相同。
- 赛后胜利、失败、统计缺失、加载失败分别在两档小窗检查，另 8 个场景。展开复盘、提交一次荣誉投票、进入历史战绩均完成桥接验证。
- 操作验证：登录输入校验和密码显隐、两种启动入口、方案选择 / 应用 / 撤回、英雄与分路搜索、对位切换与刷新、建议生成与 Ban 选中、回放、阵容复制、静音、共用连接保存 / 测试 / 清除、独立提示词、失败重试及旧推荐清除。
- `npm run typecheck` 与 `npm run build` 通过；`npm test`：265 通过，2 跳过。
- 补充检查：从历史战绩返回本局战报、大乱斗对位页返回入口、十组设计对照图片加载均通过。
- 原始记录：`output/implementation-preview/parity-validation.json`、`parity-postgame-validation.json`、`parity-final-validation.json`；重复检查脚本也在该目录。

## 数据导致的合理差异

胜率、样本、英雄数量 / 顺序、方案装备数量、教练建议和行数取自当前数据，不能照抄原稿的示例。图鉴尚未选择分路时用英雄称号，避免伪造英雄分路。云顶单位无法匹配头像时保留真实名称；装备暂无图标时显示装备名称。实际模型、加载、错误和忙碌状态均保留。

浏览器桥接验证不替代 Windows 真实 QQ 填写、LCU、窗口吸附、跨屏 DPI 与实际播报。安装包发布范围见 [0.2.0 说明](releases/v0.2.0.md)。
