# Rift Sidekick 0.2.0 · 街头暴走

按已确认设计稿重做客户端：独立登录窗、登录后吸附小窗，纸白、墨黑与燃橙覆盖全部页面。

- 重做备战、对位、教练、战绩、云顶、图鉴、语音、设置，以及大厅与赛后战报；固定各页操作栏，适配 430 / 390 窄窗。
- OpenAI 合并为一套地址、模型和密钥，教练与语音分别编辑提示词；保留连接测试、模型获取、本机加密与旧设置迁移。
- 增加游戏直接启动、QQ 自动填写、可选本机加密记住与启动前性能优化。验证码和大区选择在官方客户端完成。
- 增加 AI 选人 / Ban / 阵容建议，以及局内战斗夸夸和调侃；智能语音失败时回退基础规则。
- 选人自动识别模式与英雄；锁定后同步符文、召唤师技能与装备，保留写入校验、失败恢复及手动方案选择。
- 野怪计时改为自动开启游戏原生小地图高级模式，移除旧手动列表、独立计时窗及快捷键。

设计与组件已进行 31 个页面 / 状态场景检查，类型检查、生产构建和本地 265 项测试通过（2 项平台相关测试跳过）。[Windows 检查](https://github.com/wuzhenghua-xijiang/rift-sidekick/actions/runs/40466923617) 与 [签名发布](https://github.com/wuzhenghua-xijiang/rift-sidekick/actions/runs/40466923012) 均成功，Windows 的 267 项测试全部通过。新增登录、窗口吸附、跨屏 DPI、LCU 联动与实际语音仍待 Windows 真实客户端验收。

下载 `Rift-Sidekick-Setup-0.2.0-x64.exe`。0.1.6 及之后的安装版可在「设置 → 游戏 → 应用内更新」检查新版；0.1.5 及以前需手动安装。更新继续使用 Ed25519 签名清单与 SHA-512 / SHA-256 校验，安装包尚未配置 Windows Authenticode 证书。
