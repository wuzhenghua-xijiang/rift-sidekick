# Rift Sidekick 0.2.1 · 官方客户端直接启动

启动页改为先优化电脑，再打开国服官方客户端；账号登录在官方窗口完成。

- 默认自动查找游戏目录中的 `Launcher\Client.exe`，不再扫描或启动 TCLS、WeGame。旧缓存会用于定位同一安装目录的官方客户端，也能识别“英雄联盟（含经典模式）”目录。
- 移除 QQ 账号、密码、记住密码及自动填写入口；不再读取旧版登录凭证。官方窗口负责登录、扫码、验证码与大区选择，助手在实际连接后进入小窗。
- 先完成启用的性能优化，再启动客户端。启动失败会请求恢复本次优化，并显示具体原因和实际路径。
- 通过 Windows 正常启动与权限授权流程打开官方客户端；取消授权、权限拒绝、文件或依赖缺失均给出相应提示。等待官方窗口出现后才确认启动成功。
- 保留街头暴走海报、配色和小窗布局，适配 1100/840 启动窗及 430/390 小窗。

本地类型检查、生产构建与四种窗口尺寸的界面交互检查通过。[Windows 检查](https://github.com/wuzhenghua-xijiang/rift-sidekick/actions/runs/40480985839) 与 [发布流水线](https://github.com/wuzhenghua-xijiang/rift-sidekick/actions/runs/40480985575) 均成功，Windows 的 278 项测试全部通过，包括原生启动脚本解析与窗口检查代码编译。已下载发布文件，核对安装包哈希、Ed25519 更新清单签名及更新元数据。实际国服启动、UAC、登录及对局仍待 Windows 实机验证。

下载 `Rift-Sidekick-Setup-0.2.1-x64.exe`，或在已有安装版中进入「设置 → 游戏 → 应用内更新」检查新版。更新继续使用 Ed25519 签名清单与 SHA-512 / SHA-256 校验。
