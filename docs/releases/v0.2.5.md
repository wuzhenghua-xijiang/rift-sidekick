# Rift Sidekick 0.2.5 · 情绪语音与装备重写

下载 `Rift-Sidekick-Setup-0.2.5-x64.exe`，或在助手设置中的应用内更新检查新版。

- 内置经典搭子、暴躁老哥、愤青少年、软萌甜妹和台湾软妹共 300 段情绪音频，夸夸与调侃跟随人设，音频约 10.9 MiB；播放离线，安装包不带模型或 Python。台湾软妹另有 60 句台湾口语台词，软嗲与口音效果以试听为准。自定义和 AI 新台词继续使用 Windows 系统语音。
- 装备应用改为先清空已有方案、确认清空，再注册并写入唯一的当前方案；旧装备不备份、不恢复。写入失败等待 1 秒，最多重试 2 次，共 3 次尝试。重试前检查账号、英雄、对局和选人阶段，条件改变立即停止；读回未确认不报告成功。
- 符文及召唤师技能沿用原有快照恢复；失败清理或撤回只移除本次助手装备，不重建已清空方案。
- 新增独立的自动接受对局与指定英雄秒选设置，默认关闭。秒选仅在支持的匹配/排位模式、轮到本人且英雄可用时执行，保留玩家已经手动选择的其他英雄；大乱斗不秒选。
- 更新下载支持多个镜像切换，不让单个镜像故障一直阻塞下载；继续核对签名清单、SHA-512 与 SHA-256，下载和安装仍由用户点击。

实际 Windows 安装、国服游戏内配装方案显示及语音输出仍需实机复测。

本地验证：类型检查、414 项测试及 Windows x64 生产打包通过，Windows 专属检查在 macOS 上跳过。安装包内主进程与本次构建完全一致，包含清空重写、1 秒两次重试及 300 段音频，音频哈希逐一匹配。Windows 云端检查只有在系统确认音频输出设备数为零时才跳过实际播放，并继续验证语音脚本的错误处理；实际试听仍需带音频设备的 Windows。正式发布附件由 Windows 流水线重新构建，安装包哈希以该 Release 的 `SHA256SUMS.txt` 和签名清单为准。
