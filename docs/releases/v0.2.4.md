# Rift Sidekick 0.2.4 · BP 教练与阵容预测

AI 教练围绕本局阵容赢法、对手威胁与选择代价给出 BP 结论；双方全部锁定后，提示词要求同时输出双方胜率估计、关键理由和一句简短阵容点评。

- 教练先识别客户端、英雄资源、统计和公告版本，匹配后再使用版本证据；未知或不匹配的数据不作为当前版本强度依据。
- 选人明确首选与各有用途的备选，Ban 说明保护对象与应对机制，补位围绕同一套阵容推荐具体英雄和空缺分路。减少空泛建议与操作教程。
- 双方十名英雄确认锁定后，停止选人、Ban 和补位建议，默认输出我方／敌方百分比与轻吐槽。胜率标明「仅按阵容估计」，两方合计 100%；它是假设双方实力与熟练度相近的主观阵容判断，不是经过统计模型验证的胜率。阵容未齐不提前预测；海克斯强化资料缺失时不输出数值。
- 每个英雄、分路和模式最多提供十套真实方案，按完整符文与装备去重，保留来源有样本的坦克路线；不足十套时按实际数量展示。
- 修复已应用装备套装在商店排序靠后的问题：创建注册、合并、读回确认后提高自定义套装排序，重复应用复用同一套装，撤回恢复原内容及排序。
- 战斗语音提供九十句基础与人设台词，夸夸和调侃更贴近热血开黑语境；AI 语音提示词同步优化，仍按真实事件证据选择类别与台词。
- 默认播报音量提升到 65%。旧默认 35% 升级到新默认，静音与其他自定义音量保留；新版主动保存的 35% 也会继续保留。不修改系统或游戏音量。
- 补充国服官方窗口自动登录的可行性研究；本版本继续由官方窗口处理登录。

下载 `Rift-Sidekick-Setup-0.2.4-x64.exe`，或在助手「设置 → 游戏 → 应用内更新」检查新版。

本地发布前检查：类型检查、329 项测试和 Windows x64 生产打包通过，另有 6 项测试跳过；已核对安装包内版本与最新教练提示词。Windows 国服实局、阵容预测质量及中文语音仍需实际对局验收，检查项见 [Windows 验收清单](../WINDOWS-ACCEPTANCE.md)。
