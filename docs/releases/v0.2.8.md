# Rift Sidekick 0.2.8 · 战绩中心、大乱斗资料与教练优化

下载 `Rift-Sidekick-Setup-0.2.8-x64.exe`，或在助手设置中检查更新。

- **战绩中心**：按英雄、模式、胜负与分路筛选，查看近期表现、双方十人数据、对局时间线与事实性复盘，并通过官方客户端请求回放。
- **大乱斗资料**：展示英雄平衡调整、海克斯强化中文说明、搜索及表现参考，区分普通大乱斗与海克斯资料范围。
- **AI 教练**：新增个人英雄池，结合匿名近期记录与熟练度；结论和理由更短，优先一主一备，长内容与资料提醒可展开。
- **教练审核修复**：排除版本、模式或分路不符的证据；按预选和锁定状态收窄推荐；拦截已覆盖的过早胜率表达和正文与候选冲突，防止跨账号资料与过期回复混入当前分析。
- **推荐缓存**：网络失败或慢网时可读取本机方案，标明获取时间；过期或版本不匹配的方案仅供查看。

战绩详情、时间线、回放及强化资料受客户端与上游接口可用性限制。AI 数值倾向仍是未经校准的阵容估计，当前没有可交换英雄池、已选强化或逐技能交互的完整证据；真实模型内容质量及 Windows 国服实局联动仍需验证。详见[功能与验证范围](../HISTORY-ARAM.md)和[教练审核](../AI-COACH-AUDIT.md)。

正式安装包由 Windows 发布流水线执行类型检查、测试与打包后生成。随包提供 `SHA256SUMS.txt`、`latest.yml` 和 Ed25519 签名的 `update-manifest.json`；清单签名不等于 Windows 发布者代码签名。
