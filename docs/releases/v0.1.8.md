# Rift Sidekick 0.1.8

修正侧栏与 LOL 客户端的吸附间隙，完善装备套装创建与提示，并新增可关闭的游戏内野怪计时小窗。

- 吸附不再预留 6px，优先使用 Windows 可见边框，左右两侧均贴边。
- 新装备套装先创建注册，再合并和读回核验；校验包含套装类型、地图、模式与装备组。失败保留补偿机制，不覆盖玩家其他套装。
- **装备入口：游戏内按 P → 物品套装 → 选择「Rift · 英雄 · 方案」**。接口不会替换原生“推荐”页或强制切换商店标签。
- 经典峡谷中，大小龙根据本机公开击杀事件自动计时；红蓝 Buff、普通营地和河蟹支持手动标记。显示来源和估算状态，龙魂/远古龙及数据缺失分别处理。
- 小窗默认鼠标穿透，`Alt+Shift+J` 切换操作；点营地标记、右键撤销，支持拖动、分类、收起及本局隐藏。快捷键失败时直接显示托盘入口。
- 切出游戏、最小化或游戏数据不可用时隐藏；新一局清空旧标记。大乱斗、海克斯、云顶、斗魂、快速模式不套用峡谷计时。
- 偏好设置可关闭计时或调整估算刷新间隔，原主侧栏保持开局隐藏、赛后恢复。

建议游戏使用无边框窗口模式。计时窗为独立系统窗口，不注入游戏，不读取迷雾中的普通营地击杀。此次通过自动化及隔离 Electron 界面检查，原生观察脚本由 Windows CI 检查；新增行为仍待 Windows 真实 LOL 对局验证。

已安装 0.1.6/0.1.7 可在偏好设置检查更新；0.1.5 及以前需手动安装新版。更新继续使用签名清单和双哈希，安装包暂未配置 Windows Authenticode 证书。
