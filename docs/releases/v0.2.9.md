# Rift Sidekick 0.2.9 · 装备散件与配置残留修复

下载 `Rift-Sidekick-Setup-0.2.9-x64.exe`，或在助手设置中检查更新。

- **散件与中间件**：游戏商店套装按对应版本的合成配方展开基础散件和中间件，保留核心成装、鞋子与后续成装；来源提供出门装时一并导出，正确保留药水数量。旧缓存方案应用时也会补齐散件，卡片继续展示六件成装。
- **符文页清理**：重新识别历史 `Rift ·` 页面，复用一张可编辑助手页并清理重复页；显式关闭临时推荐标记、切换当前页并读回检查。个人页与只读预设页不参与重复页清理，撤回可恢复被清理的助手页。
- **装备排序与 WeGame 残留**：套装按 `sortrank: 0` 写入，同时同步相同 UID 的游戏全局推荐文件。清理当前英雄适用、带 Rift 或 WeGame/TGP 来源标记的旧推荐；磁盘文件操作前独立备份，无来源标记的个人推荐和其他英雄专属文件保留。
- **失败与冲突处理**：文件写入失败、换英雄/账号或其他助手重新生成推荐时停止装配并尝试撤回本次写入；不会覆盖已手工修改的推荐文件。

本地验证：49 个测试文件、542 项测试、类型检查及生产构建全部通过。正式安装包由 Windows 发布流水线再次检查并打包，提供安装器、blockmap、`latest.yml`、`SHA256SUMS.txt` 和签名更新清单 `update-manifest.json`。清单签名不等同于 Windows 发布者代码签名。

进入游戏后按 P → 物品套装查找 Rift 方案；此功能不替换游戏原生的“推荐”标签。默认选中项、实际显示顺序及符文界面刷新仍待国服自定义对局复测。WeGame 若持续开启装备同步，可能在装配结束后再次写入，请关闭其装备同步后复测。详见 [Windows 实机验收清单](../WINDOWS-ACCEPTANCE.md)。

独立备份覆盖本次处理的磁盘推荐文件。保留项目原有“清空旧 LCU 装备套装且不备份”的行为；撤回不会恢复已经清空的旧 LCU 套装。
