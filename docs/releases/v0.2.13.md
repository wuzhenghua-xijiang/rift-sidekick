# Rift Sidekick 0.2.13 · 符文与出装同步修复

下载 `Rift-Sidekick-Setup-0.2.13-x64.exe`，或在助手设置中检查更新。

- **换英雄后自动刷新**：大乱斗更换英雄后，按当前英雄重新获取并应用推荐，避免旧选人记录阻止切换。
- **符文页正确切换**：更新助手符文页名称并确认当前选中页，避免一直显示上一位英雄的名字。
- **装备分组更清楚**：游戏内物品套装按「初始装 → 中间装 → 成装 → 其它推荐装备」排列。兼容客户端对装备文件地图标记的改写，修复因此卡住恢复和应用的问题。
- **双击方案即可应用**：单击选择并保存偏好，双击或 Enter 应用符文和装备；底部移除应用按钮，连续操作不会重复启动配置。
- **应用成功后发送聊天提示**：在本局选人聊天中发送当前英雄的配置提示。聊天室暂未就绪时短暂等待；发送未确认会显示结果，已配好的符文和装备会保留。
- **减少小窗短暂空白**：客户端选人资料临时读取失败时保留吸附小窗并等待刷新，调整窗口恢复时的渲染节流。
- **默认开局偏好**：设置页功能默认开启，语音默认使用台湾软妹；秒选仍需先指定英雄，已保存的个人偏好继续生效。

本机完成客户端验证，用户确认无问题；598 项测试、类型检查、生产构建和 300 段内置语音完整性检查通过。430/390 小窗、登录与大厅完成组件截图验收。依赖冷启动环境的原生启动器集成测试未计入本轮通过数。

Windows 安装包由本机构建，更新清单由仓库现有密钥签名。Release 提供安装器、blockmap、`latest.yml`、`SHA256SUMS.txt` 和 `update-manifest.json`。
