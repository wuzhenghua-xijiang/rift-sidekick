# Rift Sidekick 0.2.12 · 开黑语音更新

下载 `Rift-Sidekick-Setup-0.2.12-x64.exe`，或在助手设置中检查更新。

- **五种声线完整更新**：经典搭子、暴躁老哥、愤青少年、软萌甜妹、台湾软妹，各有 50 段夸夸和 10 段嘲讽，共 300 段。开发侧使用 VoxCPM2 和已确认的合成参考声线制作，保留原速、换气和自然停顿，仅统一响度。
- **台湾软妹前后统一**：夸夸与嘲讽沿用已选的年轻、轻巧台湾声线；两段已确认试听直接保留原始录音，减少独立声音设计带来的变化。
- **嘲讽更直接**：五个人设共 50 句游戏互损，增加泉水、黑屏、血条等包袱，减少每句结尾的温柔劝说。只围绕游戏表现，不改变事件识别依据。
- **轻量离线播放**：音频为 48 kHz 单声道、96 kbps MP3，300 段音频合计约 12.42 MiB。客户端只播放内置音频，合成模型、Python 和参考 WAV 不进入安装包。
- **AI 台词更像聊天**：默认偏向简短口语和所选人设，普通生成台词超过 36 字时回退基础台词；用户自定义的专属台词仍保留原有上限。Windows 系统语音兜底调整语速，并按语速区分缓存。

本地发布副本通过 565 项测试、类型检查与构建。音频检查覆盖默认台词的一一对应、参考文件和成品哈希、300 段解码、原始时长保留、异常语速及包体上限；300 段静音语音识别筛查已完成，标记录音重做后复查通过。识别分数不能替代真人感、口音和情绪的听感判断；本次以已确认试听作为声线参考。

正式流水线在 Windows 执行类型检查、测试、安装包构建和更新清单签名，提供安装器、blockmap、`latest.yml`、`SHA256SUMS.txt` 和 `update-manifest.json`。自定义及 AI 新台词仍使用 Windows 本机中文语音，表现取决于系统引擎；本次没有完成 Windows 实局听感或安装重启验收。原有四组出装、配置恢复和后台行为继续沿用。请在本局结束后更新。
