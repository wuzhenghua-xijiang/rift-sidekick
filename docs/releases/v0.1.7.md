# Rift Sidekick 0.1.7

新增应用内更新，使用 GitHub 正式发布和镜像下载，方便后续在助手里完成升级。

- 偏好设置顶部检查新版、下载并显示进度；下载完成后安装并重启。
- 更新清单用 Ed25519 签名，下载后及安装前校验 SHA-512/SHA-256。
- 选人、匹配、对局及配置写入期间阻止安装，返回大厅后继续。
- 新版本提示、失败重试、缓存复核及托盘退出保护。
- GitHub Actions 自动构建 Windows x64 安装包并发布签名更新文件。

0.1.5 及更早版本需先手动安装一次新版；0.1.6 已支持应用内更新。

本次已通过自动化与 Windows CI 构建；真实 Windows 的安装重启和 LOL 客户端联动仍需实机验收。安装包暂未配置 Windows Authenticode 证书。
