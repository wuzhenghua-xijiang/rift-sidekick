# Rift Sidekick 0.2.10 · 出装分区与符文刷新修复

下载 `Rift-Sidekick-Setup-0.2.10-x64.exe`，或在助手设置中检查更新。

- **四阶段出装**：从上往下为出门装 → 过渡 → 中间套 → 成装。每阶段只保留一栏，合并重复配方散件；成装栏完整保留原方案装备，不再为每件成装单独插入散件分区。来源未提供出门装或配方没有某一阶段时省略空栏。
- **统一游戏套装文件**：更新当前英雄的 `RIOT_ItemSet_1.json`，消除同一 UID 的全局版与英雄版重复。清理 0.2.9 留在全局目录的旧 Rift 副本，并识别实机发现的 `Pallas` / `101资料站` / `LOL_` 来源推荐；操作前仍独立备份。
- **符文下拉刷新**：助手自己的符文页改为删除并重建，以发送完整的页面删除/创建事件；不再沿用旧页面的图标、推荐来源和显示元数据。页面名称使用英雄与基石符文，设置当前页后同时核对页列表与 `currentpage` 接口。个人页与只读预设页保留。
- **恢复顺序**：重建失败可恢复原符文页和原选中状态，包括创建已生效但响应丢失的情况。先撤回 LCU 装备，再恢复磁盘推荐文件，避免客户端导出再次覆盖已恢复的文件；中途导出的文件也纳入恢复记录。

本次通过只读检查定位到 0.2.9 实机存在的十个出装分区、未识别的 Pallas 全局推荐，以及同 UID、排序为 9999 的 Riot 导出副本。自动回归覆盖四阶段顺序、散件去重、旧文件迁移、Riot 导出竞争写入及符文重建失败恢复。

正式安装包由 Windows 发布流水线重新执行类型检查、测试与打包，提供安装器、blockmap、`latest.yml`、`SHA256SUMS.txt` 和签名更新清单。请在本局结束后更新，并在下一次选人及自定义对局检查实际显示：默认选中项和符文下拉框中“-”的消失仍需实机复测，自动读回不能替代界面验收。对局内不改写配置；WeGame 持续同步仍可能重新生成推荐。

无来源标记的个人磁盘推荐和其他英雄的专属文件保留。项目原有“清空旧 LCU 装备套装且不备份”的行为不变，独立备份覆盖本次处理的磁盘文件。详见 [Windows 实机验收清单](../WINDOWS-ACCEPTANCE.md)。
