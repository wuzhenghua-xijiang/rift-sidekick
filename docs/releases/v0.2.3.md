# Rift Sidekick 0.2.3 · 冠军画报与人机自动配置修复

赛后改为用户已确认的「冠军画报」构图，沿用当前街头暴走的纸白、墨黑和燃橙，灰阶英雄原画配合巨幅英雄名、赛事刊头与细分隔线。

- 海报跟随本局英雄与胜负，保留真实 KDA、参团率、伤害占比、补刀、完整复盘及手动点赞。缺失统计显示「—」，错误可重试；不可用原画隐藏，避免错误替图。支持 430×720 与 390×560，内容独立滚动，底栏固定可操作。
- 对局、战绩和赛后统一使用「召唤师峡谷」「经典召唤师峡谷」「极地大乱斗」「海克斯大乱斗」等模式名称。优先使用客户端提供的国服峡谷名称，补充 Swiftplay 队列识别；本局模式随结算报告保留，回大厅后不会被新队列覆盖。
- 修复人机、快速模式等无分路信息时无法自动配置的问题：优先保存偏好，再查询该英雄常用分路；不可用时提示手动选择。兼容旧版选人最终阶段没有操作历史的英雄锁定。
- 修复同一局模式信息短暂缺失时中断自动配置上下文或战斗语音，以及人机战斗事件使用英雄名导致未识别的情况；镜像英雄身份不明确时不猜测。
- 保留先优化再直接启动国服 `Launcher\Client.exe` 的流程，登录在官方窗口完成。

界面使用正式 React 组件与明确标记的静音模拟数据进行尺寸、状态和操作验证；测试与发布检查记录见仓库 [设计对照](../DESIGN-PARITY.md) 及 [Windows 验收清单](../WINDOWS-ACCEPTANCE.md)。这些检查不替代真实国服人机对局、LCU 写入与中文语音验收。

下载 `Rift-Sidekick-Setup-0.2.3-x64.exe`，或在助手「设置 → 游戏 → 应用内更新」检查新版。
