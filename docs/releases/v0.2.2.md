# Rift Sidekick 0.2.2 · 修复官方客户端未启动

修复 0.2.1 在存在残留后台进程时，点击启动却没有打开官方客户端的问题。`Launcher\Client.exe` 仍是国服官方登录入口。

- 判断客户端已打开时，必须存在当前 Windows 会话中的可见客户端窗口。只有无窗口的 `LeagueClient.exe` 等残留后台进程时，助手会继续完成性能优化并启动所选官方程序。
- 识别并唤回 `Launcher\Client.exe` 的官方登录窗口，重复点击不再启动另一个实例。
- 启动错误区分状态检查、显示已有窗口、文件检查、性能优化及实际启动阶段，并显示可用的系统错误码和实际路径。
- 增加 Windows 原生测试：先复现后台进程导致启动被跳过，再使用中文、空格及括号路径中的临时窗口程序验证真实 ShellExecute、工作目录、窗口确认和再次唤回。测试程序没有账号、网络或游戏行为，不能替代真实国服登录与 UAC 验收。

[Windows 检查](https://github.com/wuzhenghua-xijiang/rift-sidekick/actions/runs/40486214312) 与 [发布流水线](https://github.com/wuzhenghua-xijiang/rift-sidekick/actions/runs/40486226106) 均成功，284 项测试全部通过，包含实际启动临时窗口程序的原生测试。本地类型检查及启动相关测试通过。2026-10-27 用户随后反馈助手启动客户端成功；UAC、登录及其他实局行为仍按验收清单继续确认。

已下载发布的安装包，核对内置版本及修复代码、Ed25519 更新清单签名、SHA-512 / SHA-256 与更新元数据，并验证现有 0.2.1 的更新策略接受此版本。

下载 `Rift-Sidekick-Setup-0.2.2-x64.exe`，或在已安装的助手中进入「设置 → 游戏 → 应用内更新」检查新版。登录继续在官方客户端内完成。
