# Rift Sidekick 0.2.11 · 四组出装与后台优化

下载 `Rift-Sidekick-Setup-0.2.11-x64.exe`，或在助手设置中检查更新。

- **游戏商店最多四组**：按 **P → 物品套装 → `Rift · 英雄 · 方案`** 查找。从上往下为出门装、核心装（含鞋）、后续成装、其它推荐装备；省略没有来源数据的空组。出门装沿用当前英雄、分路和来源模式的真实组合，保留两瓶药水等数量。
- **其它推荐装备**：最多六件有统计来源的备选成装，供按局势替换。剔除默认装备、组件、鞋子、商店不可购买及当前地图不可用的条目；坦克路线保留防御候选。备选不计入默认六件套，也不改变已保存的方案偏好。
- **保留默认出装**：核心装与后续成装合计保留原方案六件装备，助手卡片继续展示原六件成装。海克斯仍明确使用普通大乱斗装备参考，不套用其符文或胜率。
- **减少后台工作**：进入游戏或隐藏助手时停止吸附辅助进程，重新显示时恢复；没有修改游戏优先级时复用当次进程查询结果，状态未变时不重复推送。
- **沿用 0.2.10 的配置修复**：符文页删除重建、推荐文件备份、LCU 事务及失败恢复流程保持原实现；旧缓存应用时按新分组重新整理。

本地类型检查、回归测试与构建通过，另对排位、普通大乱斗、海克斯装备参考共 30 套实际统计数据校验了四组顺序、药水数量、六件装备完整性及备选去重。正式发布流水线在 Windows 重新执行类型检查、测试、安装包构建与更新清单签名，提供安装器、blockmap、`latest.yml`、`SHA256SUMS.txt` 和 `update-manifest.json`。

本次四组布局尚未完成 Windows 游戏内视觉验收，自动读回与导出数据校验不能替代此项实测；后台优化也不代表已经测得具体 CPU 或内存降幅。请在本局结束后更新，并在下一局检查商店实际显示。详见 [Windows 实机验收清单](../WINDOWS-ACCEPTANCE.md)。
