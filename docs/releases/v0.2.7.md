# Rift Sidekick 0.2.7 · AI 教练版本依据修复

下载 `Rift-Sidekick-Setup-0.2.7-x64.exe`，或在助手设置中检查更新。

- 修复大厅分析跳过客户端版本读取的问题。已连接客户端时读取实际游戏版本，离线预览明确使用资源版本作为参考；版本接口暂不可用时，下次分析重新读取。

正式安装包由 Windows 发布流水线执行类型检查、测试和构建后生成。下载校验以本 Release 的 `SHA256SUMS.txt`、`latest.yml` 与签名更新清单 `update-manifest.json` 为准。
