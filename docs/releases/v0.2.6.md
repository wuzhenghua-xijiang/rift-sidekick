# Rift Sidekick 0.2.6 · 启动恢复与战场播报

下载 `Rift-Sidekick-Setup-0.2.6-x64.exe`，或在助手设置中检查更新。

- 修复二次打开助手后，残留性能恢复记录导致“请先恢复”而不能继续启动的问题。点击“优化并启动”会先自动重试恢复上次设置，恢复成功后继续检查与启动；恢复仍失败时保留原始记录和实际错误。
- 教练提示词默认填入可编辑的 BP 教练描述，覆盖版本证据、英雄克制、阵容协同和最终阵容点评。保留已有自定义内容，清空并保存后恢复默认。
- 取消战斗语音的固定播报间隔和调侃冷却。基于本人参与的真实战斗事件触发，同一波事件继续合并、去重；播放期间不叠音，不补播重连前的旧事件。
- 备战页和游戏设置增加“屏蔽所有玩家聊天”开关，默认关闭。开局前通过客户端设置屏蔽队友与对手聊天，保存并读回核验；关闭后按账号恢复原先选项，尊重后续手动修改。加载和对局期间延后配置至大厅。

Windows 实际二次启动、国服聊天屏蔽效果和游戏内声音仍需实机复测。

本地验证：类型检查通过，436 项测试通过、8 项 Windows 专属测试在 macOS 跳过；49 项静音界面检查通过，保留 21 张截图及 430/390 同尺寸对照。解包本地安装器后确认全部 37 个构建文件与本次输出一致，300 段音频逐项通过清单哈希核验。正式发布附件由 Windows 流水线重新构建，安装包哈希以本 Release 的 `SHA256SUMS.txt`、`latest.yml` 和签名清单 `update-manifest.json` 为准。
