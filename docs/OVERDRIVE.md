# 街头暴走 · 客户端实现

已确认的设计接入正式 React/Electron 入口，开发启动仍使用 `npm run dev`。设计场和交互验收页不进入生产构建。

## 窗口与页面

- 未连接客户端：独立 1100×740 启动窗，QQ 自动填写、记住密码、启动优化、官方登录、游戏位置与设置。
- 连接后：默认 430 DIP 吸附侧窗，最小 390 DIP。跟随客户端位置和高度，保留前台、最小化、托盘及开局隐藏逻辑。
- 八个入口：备战、对位、教练、战绩、云顶、图鉴、语音、设置。启动和账号工具位于「设置 → 游戏」。
- 纸白、墨黑、燃橙覆盖全部页面；方案按原稿排列编号、标题、右上胜率、装备、样本与符文技能，完整符文和说明可展开查看。
- 设置采用原稿的 OpenAI / 语音 / 游戏分组；生成建议、刷新战绩、复制阵容和保存配置均使用本页固定底栏。
- 登录原画为 Riot 官方「双城之战2 破碎者 金克丝」，作为本地资源随应用打包，来源见 `THIRD-PARTY-NOTICES.txt`。

「使用官方登录」只跳过这一次 QQ 自动填写，不清除或关闭已有账号设置。验证码、大区和风控步骤仍由官方窗口处理。

## OpenAI

设置中的 OpenAI 是唯一连接表单，地址、模型、密钥由教练和战斗语音共用。教练偏好和语音风格分别编辑、分别应用，共用一次保存操作。

沿用本机加密的 `ai-coach.json`。首次迁移优先保留已有教练连接；教练没有密钥时导入旧语音连接，并保留语音提示词。成功迁移后移除偏好中的重复密钥；失败时保留旧数据。更换接口地址仍要求重新填写密钥，已存密钥不返回渲染进程。

语音使用 Responses，教练使用 Chat Completions；供应商需要支持相应用法。语音调用失败仍回退基础规则。

## 验收

`npm run typecheck`、`npm test`、`npm run build`。主进程测试覆盖登录窗切换、吸附启停、官方登录跳过自动填写、自动配装、密钥迁移、独立提示词及移除共用密钥。

`output/implementation-preview/` 使用正式组件与验收桥，所有数据明确标为示例，语音静音。用于核对登录、八页布局和操作派发，不能证明 Windows QQ 填写、Win32 吸附、实际语音和 LCU 行为。截图位于 `output/playwright/implementation-*.png`。

2026-10-27 对照修订：视觉基准固定为根目录 [DESIGN.md](../DESIGN.md) 所指的最新设计稿，后续修改必须先核对稿件。正式样式直接移植到 `overdrive-reference.css`。本轮八页与原稿同尺寸并排核对，包含 390/430 两档、登录和大厅，关键交互记录在 `output/implementation-preview/parity-validation.json`，最新截图与对照板位于 `output/playwright/parity-*`。
