# 野怪计时：原生小地图

## 0.2.0：原生小地图自动计时

按用户确认的“小地图各营地位置”方式实现。助手连接 Windows LOL 客户端后，默认自动开启游戏原生的高级小地图计时；营地击杀、刷新、位置、视野及计时显示由游戏负责，不需要手动点营地、坐标校准或助手自行估算刷新间隔。Riot 在 [25.17 补丁说明](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-17-notes/) 中介绍了此原生能力。

此改动纳入 0.2.0；0.1.8 及更早安装包不包含这些调整。Windows LOL 实局行为仍待验收。

- 入口：偏好设置 → 自动开启小地图营地计时，默认开启。
- 在大厅、选人等非对局阶段检查设置接口，要求现有设置中有 `HUD.MinimapEnableAllTimers`。只 PATCH 此选项，保留原值类型，保存并读回；确认后才显示“已确认开启”。
- 已开启时只读取确认，不反复写入。就绪等待最多自动尝试三次，每次间隔至少 10 秒；其他失败需点“检查并开启”重试。
- 账号或对局阶段改变时取消过期请求；加载、对局和重连期间延后写入。
- 无对应选项、接口错误、保存未确认或读回不一致时提示原因，不声称配置成功。
- 游戏内可自行按 Esc → 界面 → 小地图野怪计时，选择“高级”；具体中文名称以当前国服为准。
- 关闭自动配置只停止助手继续配置，已经开启的游戏选项可在游戏内调整。
- 按用户要求彻底移除手动列表、独立悬浮窗、标记与规则设置、Alt+Shift+J 快捷键、托盘入口及对应 IPC；不再轮询 2999 游戏数据或观察游戏窗口。旧手动计时偏好不再加载、保存，保留旧配置文件也不会重新启用。

实现为游戏设置接口适配，不注入进程，不改客户端文件。设置键名在 [GitHub 游戏配置样本](https://github.com/ThuHub/LOL_Setting_Sync/blob/8e51b96e094909be7cc9cec33a8d458cc7ea5a02/英雄联盟/Game/Config/game.cfg) 中核实，端点由 [LCU 接口定义](https://github.com/KebsCS/lcu-and-riotclient-api/blob/main/lcu/swagger.json) 核实。运行时仍须当前客户端确实返回该选项，不能将社区定义当成所有区服永久支持的保证。

专项测试覆盖只改一个 HUD 字段、保存与读回、原本已开启、未知选项、对局中延后、账号切换、限次等待、保存失败重试、读回不一致、请求超时已生效、关闭后忽略迟到响应，以及非 Windows/离线零请求。尚未进行 Windows LOL 实局验证。
