# 野怪计时：0.1.8 功能与界面记录

野怪计时是 Windows 专用的独立小窗，用于记录本局已知的野区信息。主助手侧栏在游戏内继续隐藏；计时窗单独跟随游戏窗口显示。本文记录当前源码行为，Windows 真实对局验收仍待完成。

## 显示与操作

- 默认鼠标穿透，按 **Alt + Shift + J** 切换操作模式，再按一次恢复穿透。
- 快捷键注册失败时，从托盘选择“显示/操作野怪计时”，然后返回游戏操作；窗口失去游戏前台条件时会隐藏。
- 操作模式下，左键点击条目记录“刚刚击杀”，以当前游戏时间起算。请只记录自己看到并确认的击杀；Buff、普通营地与河蟹不会自动读取击杀。
- 右键只撤销该条目的**手动记录**，不会删除公开事件；撤销后可恢复事件记录、首刷参考或待标记状态。
- 可拖动标题区调整本局位置，切换“大小龙 / Buff”和“普通营地”，或收起窗口。关闭按钮隐藏本局计时窗，可用快捷键或托盘入口重新显示。

手动记录与公开事件同时存在时，以时间较新的记录生效。手动标记不会跨局保存。

## 来源与可信度

| 界面标签 | 实际来源 | 阅读方式 |
| --- | --- | --- |
| 事件 | Live Client Data 的 `DragonKill` / `BaronKill` | 按公开击杀时间加刷新间隔估算 |
| 手动 | 用户点击记录的游戏时间 | 按确认击杀时间加刷新间隔估算 |
| 首刷 | 本地首刷参考时间 | 仅提示预计首次出现，不确认当前存活 |
| 待标记 | 营地首刷时间已过，且没有有效击杀记录 | 显示 `—`，不猜测下一次刷新 |

倒计时到零显示“预计刷新”，不等于已观察到刷新。普通营地不读取迷雾信息，也不提供隐藏的敌方营地状态。

巨龙与纳什男爵优先使用公开击杀事件。元素龙事件会按击杀者所属队伍累计；确认同队四条元素龙后切换到远古巨龙，明确的远古龙击杀事件也使用远古龙间隔。若无法确认元素龙归属，且龙魂状态尚未明确，则保留“事件”来源并将刷新时间显示为 `—`；后续玩家身份补齐时会重新核算，避免重复计数或强行猜测龙魂。

## 适用模式与生命周期

当前仅接受队列 ID **`0`、`400`、`420`、`430`、`440`、`700`**，同时要求客户端内部模式识别通过、游戏地图为 `11`、游戏模式为 `CLASSIC`。其他队列不会套用这些规则；大乱斗、海克斯大乱斗、快速模式及轮换模式不在支持范围。

对局开始后，以 2 秒间隔读取本机 `https://127.0.0.1:2999/liveclientdata/allgamedata`。游戏窗口不存在、最小化、失去前台条件，或本地游戏数据读取失败时隐藏计时窗；数据连接恢复后自动继续。数据过期时不能继续标记，避免把旧样本写成本局击杀。

检测到新对局会清空击杀记录，并重置交互模式、本局隐藏状态和拖动偏移；游戏时间明显回退也会清空计时追踪。临时 LCU 断连本身不会清空正在进行的计时。

## 刷新规则

偏好设置可调整以下估算间隔，单位为秒，均须为 **30–1200 的整数**；支持保存和恢复默认值。

| 类型 | 默认间隔 |
| --- | ---: |
| 红 / 蓝 Buff | 300 |
| 普通营地 | 135 |
| 河蟹 | 150 |
| 元素巨龙 | 300 |
| 远古巨龙 | 360 |
| 纳什男爵 | 360 |

首刷参考时间来自 26.1 规则背景，当前代码取值为：红蓝 Buff、三狼、锋喙鸟 `0:55`，魔沼蛙、石甲虫 `1:07`，河蟹 `2:55`，元素巨龙 `5:00`，纳什男爵 `20:00`。首刷时间不在设置表中；这些本地取值不保证与当前补丁、特殊玩法或具体对局规则完全一致。修改刷新间隔也不会校正首刷时间。

参考：[Riot Live Client Data API](https://developer.riotgames.com/docs/lol#game-client-api_live-client-data-api)、[Riot 26.1 补丁说明](https://www.leagueoflegends.com/en-us/news/game-updates/patch-26-1-notes/)。

## 当前视觉设计

延续主助手的深紫色界面：窗口背景（`#191823`）、更深的标签栏（`#11101a`）、荧光绿强调（`#caff43`）与粉色操作状态（`#fc62ba`）。荧光绿用于计时标识、键盘焦点与“预计刷新”；粉色提示正在操作。阵营另用蓝色和浅粉色小标签区分，避免与倒计时状态混淆。

窗口采用无边框、紧凑纵向布局，常规尺寸为 **264 × 394**，普通营地页为 **264 × 526**，收起高度为 **54**；实际尺寸受屏幕工作区限制。默认靠游戏窗口右侧、顶部下移 100，位置会限制在屏幕工作区内。正文以 9–12 像素呈现，倒计时用 16 像素等宽数字；标题区、标签切换和底部操作提示保持可见，较长列表在中部滚动。

偏好设置的规则表使用两列数字输入与保存反馈，窄侧栏也应保持标签、输入和操作可读。焦点框沿用荧光绿，错误与规则警告沿用暖金色。
