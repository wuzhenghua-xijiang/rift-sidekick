# Rift Sidekick · 开局整点花活

Windows x64《英雄联盟》侧边助手。深紫底色、荧光绿按钮、粉色贴纸和游戏化文案；跟随 LOL 客户端停靠，使用左侧功能列表切换推荐、对位、战绩、云顶与英雄图鉴。

**当前交付：0.1.8。改为贴边吸附，补齐装备套装创建/读回校验，新增游戏内野怪计时小窗：大小龙事件计时，Buff 与普通营地手动标记。支持 GitHub 镜像应用内更新。用户已实测符文与召唤师技能生效；本轮装备显示、吸附及计时悬浮窗仍待 Windows 实局复测。**

## 安装与使用

从 [GitHub Release](https://github.com/wuzhenghua-xijiang/rift-sidekick/releases/latest) 下载并安装 `Rift-Sidekick-Setup-0.1.8-x64.exe`，启动助手并登录 Windows 英雄联盟客户端。安装目录可以自行选择，不需要填写 API Key。0.1.5 及更早版本没有应用内更新，需要先手动安装新版一次。

1. 助手自动识别模式、英雄与分路，贴合客户端可见边缘吸附，不再预留 6px 间隙；Windows 10/11 使用 DWM 可见边框避免不可见缩放边框造成空隙。右侧放不下时移到左侧，仍不足则限制在当前屏幕工作区。
2. **“锁定后自动配置”默认开启**：锁定英雄后，自动同步该英雄、分路和模式的偏好方案；没有偏好时用胜率最高的一套，海克斯用首套装备参考。预选、取消选人、换英雄和换模式会取消旧请求。底部区分离线预览、等待锁定、数据加载、可配置和需要恢复等状态。
3. 没有分路信息的经典峡谷对局需要先点选分路；普通大乱斗使用独立数据。每套方案是一张紧凑卡片，按胜率从高到低排列，无胜率的放后面。主系展示实际基石图标和名称，副系展示选中的两枚小符文图标，右侧展示两枚推荐召唤师技能；悬停可看名称，图标均来自 LOL 资源目录。选择或保存偏好不会改变排序；“已选择”表示偏好，实际写入结果另行反馈，底部“一键配置所选方案”仅在本局可写入时启用。
4. 经典与普通大乱斗自动配置完整符文和游戏商店装备方案；界面省略主系其余小符文与碎片。召唤师技能在偏好设置中开启“同时同步召唤师技能”后才写入。海克斯大乱斗只同步装备，不请求符文页或更改召唤师技能。
5. 常规符文配置需要一个可用的自定义符文页空位，只复用助手建立的页面。装备仅保留核心成装、鞋子和后续成装，不含出门装、药水与合成小件。**装备在游戏内按 P → 物品套装 → 选择「Rift · 英雄 · 方案」查看，不是游戏原生“推荐”标签。** 新套装先通过创建接口注册，再合并并读回核验；不会删除玩家其他套装，接口也不能替玩家强制切换商店标签。
6. 可以撤回最近一次配置。接口中断时保留本地快照，重新连接原账号后恢复；如果之后手动改过助手方案，会提示冲突并保留修改，可选择“保留当前配置”。
7. 经典模式选人时，同位置对手锁定后显示“对位小抄”摘要，展开可看对手注意事项、己方技巧及分路提醒；有样本时显示该英雄对阵整场胜率。开局页默认收起详情，保留方案空间，对位手册默认展开。分路不明确时，仅在唯一敌方英雄高度常用该位置时标注推测；摇摆阵容可手动更正，只能选择已锁定的对手。离线也可选对手研究，支持外号检索。
8. 展开当前分路的热门榜，查看登场率、胜率、样本量和统计版本，点击英雄可看方案。榜单按登场率排序，数据范围为 OP.GG 全球、全段位、排位；不冒充国服统计，不用于大乱斗。
9. 进入加载、游戏和重连阶段后自动隐藏助手；短暂断开客户端接口不会让窗口突然弹回。对局结束后恢复窗口并打开本局分析，展示 KDA、参团率、伤害占比、每分钟补刀、视野和我方伤害对比。结算未到达时等待重试，缺失指标显示“—”。同次运行中切换页面、返回大厅或继续匹配仍保留上一局战报供复盘；离开结算后隐藏点赞，断开连接或进入下一局选人时清除旧战报。
10. 赛后按客户端实际票数勾选可点赞玩家，默认优先队友，点击“一键点赞”后提交荣誉投票；不会自动点赞。提交前重新检查本局、账号、票数及可选玩家。已开始提交后发生超时不重复投票，可回客户端确认结果。

11. Windows 托盘创建成功时，右上角关闭按钮隐藏到托盘；双击图标或右键“显示助手”可唤回，右键“退出助手”彻底退出。手动隐藏后不会因吸附轮询立即弹回，游戏结束仍按偏好恢复；托盘不可用时关闭按钮正常退出。

12. **应用内更新**位于偏好设置顶部：Windows 安装版启动时静默检查一次，也可手动检查；有新版本时侧栏显示更新标记。仅获取 `wuzhenghua-xijiang/rift-sidekick` 的新版正式 Release，通过 `gh-proxy.com` 镜像检索元数据并下载对应版本的更新文件。安装包须同时通过与版本/文件绑定的 Ed25519 清单签名、SHA-512 与 SHA-256 校验，安装前再次验证本地文件。下载完成后点“安装并重启”，在大厅或客户端离线时静默覆盖安装并启动助手；选人、匹配、对局及配置写入/待恢复期间会阻止安装。关闭窗口不会自行安装；镜像异常时可重试。开发预览和非 Windows 版本不启用更新。

13. **游戏内野怪计时**默认开启，主侧栏仍隐藏，仅保留一个独立小窗。大小龙从本机 Live Client Data 的公开击杀事件计时；红蓝 Buff、三狼、魔沼蛙、锋喙鸟、石甲虫、河蟹需手动标记。`Alt + Shift + J` 切换鼠标穿透/操作，点击营地记录刚发生的击杀，右键撤销手动标记；可拖动标题、收起或本局隐藏。快捷键冲突时使用托盘“显示/操作野怪计时”，回到游戏后操作。只用于经典峡谷，排除大乱斗、海克斯和快速模式；切出游戏或数据不可用时隐藏，下一局清空旧标记。倒计时为估算，刷新间隔可在偏好设置调整，建议游戏使用无边框窗口模式。详见 [计时说明](docs/JUNGLE-TIMERS.md)，[悬浮窗样例](docs/screenshots/jungle-timer-fixture.png) 使用隔离数据，不是真实游戏截图。

未连接客户端时可浏览攻略、英雄和云顶阵容。推荐、技巧、热门榜、图标与云顶阵容需要联网；失败会显示原因及重试入口。游戏中需要查看时可通过托盘或再次启动助手唤回窗口，配置写入仍限制在选人阶段。选人时浏览其他英雄/模式会出现“回到本局”入口，并禁用不匹配本局的写入。

安装包尚未配置代码签名。目标系统为 Windows 10/11 x64；本地开发与界面验收在 macOS 上进行，Windows 实机检查见 [验收清单](docs/WINDOWS-ACCEPTANCE.md)。

安装包校验文件会随 GitHub Release 一起提供，仓库也保留当前版本的 [SHA256SUMS](docs/releases/SHA256SUMS.txt)。NSIS 安装器启动程序本身是 x86，所包含的 Electron 主程序为 x64。

## 已接入的内容

| 模块 | 当前行为 |
| --- | --- |
| 客户端状态 | 连接状态、选人/加载/游戏/结算阶段、模式、英雄 ID、已分配分路、敌方预选与锁定状态 |
| 游戏专注 | 开局/重连自动隐藏，结算或返回大厅后恢复；Windows 托盘可唤回或退出 |
| 野怪计时 | 独立可关闭小窗；大小龙公开事件计时，Buff/营地手动标记，鼠标穿透、托盘回退、分模式与断线降级 |
| 多套方案 | 每次最多 5 套，使用来源实际提供的不同核心成装或主副系；独立卡片展示，不靠改名凑数 |
| 自动与手动配置 | 锁定后防抖、偏好记忆、写入前校验、写入后读取确认、失败补偿、恢复快照 |
| 对位手册 | 技能加点顺序、当前分路的英雄对阵整场胜率、样本量、已亮英雄筛选、基础连招；海克斯不套用普通大乱斗对位胜率 |
| 对位小抄 | 已锁定同位置对手识别、可修正的分路推测、双方基础技巧与分路提醒；不监测实时冷却或隐藏信息 |
| 分路热门榜 | 当前分路登场率、胜率、样本和版本，支持点选英雄；经典峡谷使用排位统计作参考 |
| 本局复盘与点赞 | 按当前账号及对局匹配结算，展示基础指标、伤害对比和复盘提示；大厅保留只读战报，结算阶段可手动一键提交荣誉投票 |
| 自己的战绩 | KDA、胜负、模式、补刀、伤害、单双排段位、熟练度；每页 20 场，最多查询 200 场，以客户端返回为准 |
| 回放入口 | 从自己的战绩请求客户端下载或观看整场回放，受版本与对局类型限制 |
| 云顶配方 | 当季实时阵容、7×4 站位、核心装备、平均名次、前四率和阵容代码复制 |
| 英雄图鉴 | 当前资源版本的全部英雄，支持中文名、称号、英文 ID、外号及拼音缩写搜索；内置 173 位英雄的搜索词与社区补充，见[词库说明](docs/CHAMPION-SEARCH.md) |

样本不足时可能少于三套方案，不伪造数据补齐。胜率仅对应核心装备或符文样本，不代表完整六件装备与符文的联合胜率。海克斯大乱斗暂用明确标注的普通大乱斗装备参考；强化符文可能改变装备优先级，不展示该模式胜率。[Riot 的模式说明](https://support.riotgames.com/en-us/league-of-legends/events/league-of-legends-aram-mayhem-game-mode)确认海克斯大乱斗关闭常规符文设置。

尚未实现的内容包括：敌方技能/眼位/水晶计时、普通营地全自动击杀识别、阵容总胜率与线杀率、实时对线事件提醒、阵亡即时回放、匿名队友侦查、斗魂竞技场实时信息、自动接受和自动 BP。计时窗是独立系统窗口，不向游戏进程注入。具体边界见 [实现矩阵](docs/IMPLEMENTATION.md)。

## 开发与打包

使用 TypeScript、React 和 Electron。Windows 连接与窗口跟随使用系统 PowerShell 和 Win32 窗口 API，不要求安装额外运行时。

```bash
npm ci
npm run dev
```

```bash
npm run typecheck
npm test
npm run dist:win
```

Node.js 24，锁定依赖见 `package-lock.json`。`dist:win` 明确指定 Windows x64；产物在 `release/`，`win-unpacked/` 为解包后的应用。GitHub Actions 配置在 `.github/workflows/windows.yml`，发布标签由 `.github/workflows/release.yml` 构建并生成签名更新清单。

## 数据与接口

- 英雄、资源版本、装备与符文目录：[Riot Data Dragon 文档](https://developer.riotgames.com/docs/lol#data-dragon)。启动后及每六小时更新资源，配置前检查客户端主次版本和符文槽位、装备适用地图、召唤师技能。
- 推荐优先使用 OP.GG 完整统计接口，获取多个真实核心装备与符文组合；失败时退回 [OP.GG 官方 MCP](https://github.com/opgginc/opgg-mcp)。云顶也通过 MCP 获取。查询自动排队，推荐缓存四分钟、云顶与分路榜缓存十分钟，遵守接口的 `Retry-After`。完整统计接口属于网站接口，可能随服务更新变化。
- LCU 为社区整理的客户端接口，**不是 Riot/Tencent 承诺稳定或批准使用的公共 API**。连接方法参考 [league-connect](https://github.com/junlarsen/league-connect)、[LeagueAkari](https://github.com/LeagueAkari/LeagueAkari) 和 [LCU 接口定义](https://github.com/KebsCS/lcu-and-riotclient-api)。接口被限制时退化为攻略展示。

`DATA` 版本是 Data Dragon 资源版本；卡片独立显示完整统计接口返回的 `meta.version`。客户端与资源或已知统计主次版本不一致时阻止写入。MCP 回退未返回统计版本时会标注未提供；无法保证统计与国服每个小更新完全同步。

所有 LCU 凭证仅在内存中用于本机 `127.0.0.1` 连接，不发送给推荐服务或更新镜像。更新镜像地址、GitHub 仓库和验签公钥内置于客户端；更新私钥仅由 GitHub Actions Secret 持有，不随代码或应用分发。设置、英雄缓存和恢复快照保存在 Electron 用户数据目录；可在 Windows 的 `%APPDATA%/rift-sidekick/` 下查看。不会修改游戏文件、注入游戏进程或操作战斗技能。

第三方资料与资源归各自权利人所有。项目未捆绑 WeGame 品牌、美术或代码，UI 使用独立设计。
